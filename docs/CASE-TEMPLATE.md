# Estrutura para ampliar um case

Este arquivo é um modelo editorial, não uma página comercial. Só preencher e incorporar ao site após confirmar as evidências e a autorização de uso.

| Campo | Evidência necessária |
| --- | --- |
| Cliente / produto e autorização | Nome permitido, responsável pela aprovação, data e canais autorizados |
| Contexto e público | Briefing ou documento aprovado pelo cliente |
| Problema | Situação inicial descrita sem inferir perdas ou impacto financeiro |
| Participação de Glauber | Responsabilidades, período, equipe e vínculo; distinguir execução direta de projeto feito para outra empresa |
| Escopo entregue | Fluxos, plataformas e integrações confirmados; separar plataforma de site comercial |
| Decisões e restrições | Registros técnicos ou materiais de projeto autorizados |
| Evidência visual | Capturas aprovadas, sem dados pessoais ou informações confidenciais |
| Resultado | Métrica, definição, período, fonte, baseline e autorização; omitir quando não disponível |
| Depoimento | Texto literal aprovado, pessoa/cargo e permissão de publicação |
| Próximo passo | Serviço pertinente e CTA específico |

## Native IP: o que já existe no repositório

- `index.html` e `js/i18n.js`, no commit inicial `4c5354b`, apresentam a **landing page para provedores de internet**, não o desenvolvimento da plataforma SaaS.
- `img/apps/lps/nativeip.webp` contém a captura já usada no portfólio.
- O link já existente é `https://nativeip.com.br/lp/provedor-internet/`.
- O detalhamento novo se restringe a contexto comercial, escopo da landing page, interface e limites da evidência. Não acrescenta logo, depoimento, métrica, arquitetura interna ou atribuição individual.

## Validação pendente do proprietário

- Confirmar autorização para manter a imagem/nome e ampliar o relato em uma URL própria; o repositório não contém termo formal de autorização.
- Confirmar participação individual, período, decisões técnicas, entregáveis e resultados antes de incluí-los.
- Para um case de **desenvolvimento do produto SaaS**, fornecer um projeto autorizado com esse escopo. A referência Native IP é identificada expressamente como landing page.
- SAMU e Unimed continuam com a atribuição existente à TRUE. O diagnóstico usa SAMU como contexto mobile/integração, sem transformá-lo em case de consultoria.
